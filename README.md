# 🚀 Banking Fraud Detection Using Machine Learning

## 📌 Project Overview
Banking Fraud Detection is a Machine Learning project designed to identify potentially fraudulent financial transactions. It uses data preprocessing, exploratory data analysis, and a Random Forest classification model to distinguish fraudulent transactions from legitimate ones.

## 🎯 Objectives
- Detect suspicious banking transactions.
- Predict the likelihood of fraudulent activity.
- Analyze transaction patterns using data visualization.
- Provide an interactive dashboard for fraud analysis.

## ✨ Key Features
- Machine Learning-based fraud prediction
- Fraud probability estimation
- Interactive web dashboard
- Transaction history tracking
- Fraud vs. legitimate transaction analysis
- Downloadable CSV reports

## 🛠️ Technologies Used
- **Programming:** Python
- **Libraries:** Pandas, NumPy, Scikit-learn
- **Web Framework:** Flask
- **Database:** SQLite
- **Frontend:** HTML, CSS, JavaScript
- **Machine Learning:** Random Forest Classifier

## 📊 Workflow
1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis (EDA)
4. Model Training and Evaluation
5. Fraud Prediction
6. Dashboard Visualization

## ⚙️ Installation and Setup

### 1. Clone the Repository
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd Banking-Fraud-Detection
```

### 2. Create a Virtual Environment
```bash
python -m venv .venv
```

Activate it on Windows:
```bash
.venv\Scripts\activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Run the Application
```bash
python app.py
```

Open your browser and visit:
```text
http://127.0.0.1:5000
```
